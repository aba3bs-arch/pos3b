# Tutorial · Cancelación / Devolución en Venta en Ruta

Guía operativa para **deshacer una venta errónea** (efectivo, crédito o mixto): inventario, CxC, RC/VentaRuta, compra y folio.

En la app: menú **Tutorial**, o el botón **Ver tutorial** en:

- Venta en Ruta → **Cancelación / Devolución**

Imágenes: `public/tutorial-cancelacion-ruta/`.

## Frase clave

**Pides · admin aprueba · inventario vuelve · crédito y efectivo desaparecen.**

## Pasos

1. **Solicitar** — Venta en Ruta → Cancelación / Devolución → elige folio + motivo → Solicitar.
2. **PIN admin** — Notificación flotante o lista de pendientes → Aprobar / Rechazar.
3. **Reversión** — Camión (Disp.) · piso si ya recibió · CxC · RC/VentaRuta · compra · venta.

## Mixto

Al cancelar un **mixto** se limpian **ambos**: efectivo en RC y crédito en CxC, más el inventario completo.

## No confundir

| Acción | Qué hace |
|--------|----------|
| **Cancelación / Devolución** | Deshace una **venta cobrada** (folio VR). |
| **Cancelar carga** | Devuelve mercancía **sin ventas** a CEDIS. |
| **Eliminar ingreso** | Solo borra el **ticket** de carga; no mueve inventario ni ventas. |
