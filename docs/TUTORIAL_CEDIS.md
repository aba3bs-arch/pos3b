# Tutorial CEDIS — catálogo, stock y salidas

Guía ilustrada en la app: menú **Tutorial** → *CEDIS: catálogo, stock y salidas a tienda/ruta*.

También: sucursal **CEDIS** → **Productos → Ver tutorial CEDIS** (o **Venta en Ruta**).

Imágenes: `/public/tutorial-cedis/*.svg`

## Pasos (resumen)

1. Login en **CEDIS** (no MAIN).
2. **Productos**: catálogo filtrado + proveedor **CEDIS LAS 3B**.
3. Departamentos propios del almacén (no mezclan el menú de tiendas).
4. Catálogo en **Proveedores → CEDIS LAS 3B**.
5. Ingreso: ajuste de inventario o recepción de compras → `stock_cedis`.
6. Traspaso CEDIS → tienda.
7. **Venta en Ruta → Carga de camión** (sale stock de CEDIS).
8. Frase: *CEDIS guarda · tienda vende en piso · camión vende en ruta.*
